---
title: "Assessments API — Coding, MCQ & Mixed Skills Tests"
description: "Create and manage coding, MCQ, and mixed assessments for candidates. Retrieve detailed score breakdowns and anti-cheat logs via the AceIntAssessments API."
---

The Assessments API lets you assign skill-based evaluations to candidates and retrieve detailed results once they complete them. AceIntsupports three assessment types: `coding` for hands-on programming challenges, `mcq` for multiple-choice question sets, and `mixed` for a combination of both.

Retrieval endpoints require the `read` scope. Creating assessments requires `write`. Deleting assessments requires `admin`.

## List Assessments

`GET /assessments`

Returns a paginated list of assessments in your organisation.

| Parameter      | Type    | Description                                                                                     |
| -------------- | ------- | ----------------------------------------------------------------------------------------------- |
| `candidate_id` | string  | Return only assessments for this candidate.                                                     |
| `role_id`      | string  | Return only assessments associated with this role.                                              |
| `type`         | string  | Filter by assessment type. Accepted values: `coding`, `mcq`, `mixed`.                           |
| `status`       | string  | Filter by assessment status. Accepted values: `pending`, `in_progress`, `completed`, `expired`. |
| `page`         | integer | Page number. Starts at `1`. Default `1`.                                                        |
| `per_page`     | integer | Number of results per page. Maximum `100`. Default `20`.                                        |

```bash
curl "https://api.aceint.dev/v1/assessments?type=coding&status=completed" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

## Create an Assessment

`POST /assessments`

Creates and assigns a new assessment to a candidate. The assessment is immediately available for the candidate to begin.

| Parameter      | Type   | Required | Description                                                                                                                          |
| -------------- | ------ | -------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `candidate_id` | string | Yes      | ID of the candidate who will take this assessment.                                                                                   |
| `role_id`      | string | Yes      | ID of the role this assessment is evaluating the candidate for.                                                                      |
| `type`         | string | Yes      | Assessment type. Accepted values: `coding`, `mcq`, `mixed`.                                                                          |
| `questions`    | array  | No       | Array of question IDs to include in this assessment. If omitted, AceIntauto-selects questions based on the role and assessment type. |

```bash
curl -X POST https://api.aceint.dev/v1/assessments \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "candidate_id": "cand_01hx4z",
    "role_id": "role_09abc",
    "type": "coding",
    "questions": ["q_001", "q_002", "q_003"]
  }'
```

## Retrieve an Assessment

`GET /assessments/{id}`

Returns a single assessment record by ID, including its current status and the list of assigned questions.

```bash
curl https://api.aceint.dev/v1/assessments/asmt_03ghi \
  -H "Authorization: Bearer YOUR_API_KEY"
```

## Get Assessment Results

`GET /assessments/{id}/results`

Returns the full results for a completed assessment, including a per-question score breakdown and an anti-cheat log.

<Callout title="Note">
  This endpoint returns `404` until the assessment reaches `completed` status.
  Subscribe to the `assessment.completed` webhook event to be notified as soon
  as results are available.
</Callout>

Response fields include:

- **score_breakdown** — per-question scoring details.
- **anti_cheat_log** — integrity signals captured during the assessment session, including a `flags` array (e.g. `"prolonged_tab_switch"`, `"high_paste_frequency"`).

```bash
curl https://api.aceint.dev/v1/assessments/asmt_03ghi/results \
  -H "Authorization: Bearer YOUR_API_KEY"
```

## Delete an Assessment

`DELETE /assessments/{id}`

Permanently deletes an assessment and all associated result data.

<Callout title="Warning">
  This action is irreversible. Export or archive any results you need before
  calling this endpoint.
</Callout>

Returns HTTP `200 OK` with an empty `data` object on success.

```bash
curl -X DELETE https://api.aceint.ai/v1/assessments/asmt_03ghi \
  -H "Authorization: Bearer YOUR_API_KEY"
```
