## Overview

The Agents framework lets you add any Python or Node.js program to Ribbon rooms as a full
realtime participant. Build agents with code using the Python and Node.js SDKs, or use the
Agent Builder to prototype directly in your browser. The framework provides tools and
abstractions for feeding realtime media and data through an AI pipeline that works with any
provider, and publishing results back to the room.

Use Ribbon Cloud to start building agents right away, with managed deployment, built-in
observability with transcripts and traces, and hosted inference for running models without
your own API keys.

## Key concepts

### Multimodality

Agents can process and respond with speech, text, and video in the same session, switching
modes based on what the conversation calls for.

### Logic & structure

Sessions, chat context, tasks, and workflows give you predictable building blocks for agent
behavior, from simple Q&A to long-running multi-step tasks.

## Getting started

Follow the Voice AI quickstart to build your first agent, or try Agent Builder to prototype
without writing code.
