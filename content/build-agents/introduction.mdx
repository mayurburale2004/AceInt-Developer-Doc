## Overview

The Agents framework lets you add any Python or Node.js program to Ribbon rooms as a full
realtime participant. Build agents with code using the Python and Node.js SDKs, or use
Agent Builder to prototype and deploy agents directly in your browser without writing code.

### Use cases

Some applications for agents include:

- **Multimodal assistant**: Talk, text, or screen share with an AI assistant.
- **Telehealth**: Bring AI into realtime telemedicine consultations, with or without humans in the loop.
- **Call center**: Deploy AI to the front lines of customer service with inbound and outbound call support.
- **Realtime translation**: Translate conversations in realtime.
- **NPCs**: Add lifelike NPCs backed by language models instead of static scripts.
- **Robotics**: Put your robot's brain in the cloud, giving it access to the most powerful models.

### Framework overview

Use Ribbon Cloud to start building agents right away, with managed deployment, built-in
observability with transcripts and traces, and hosted inference for running AI models
without API keys. You can deploy your agents to Ribbon Cloud or any custom environment of
your choice.

### How agents connect to Ribbon

If you want to get your hands on the code for building an agent right away, follow the
Voice AI quickstart guide or try out Agent Builder and build your first voice agent in

## Key concepts

### Multimodality

Agents can process and respond with speech, text, and video in the same session, switching
modes based on what the conversation calls for.

### Logic & structure

Sessions, chat context, tasks, and workflows give you predictable building blocks for agent
behavior, from simple Q&A to long-running multi-step tasks.

### Agent server

Agent servers manage the lifecycle of your agents, handling dispatch, job execution, and
scaling. They provide production-ready infrastructure including automatic load balancing
and graceful shutdowns.

### Models

The Agents framework supports a wide range of AI models for LLMs, speech-to-text (STT),
text-to-speech (TTS), realtime APIs, and virtual avatars. Use Ribbon Inference to access
models directly through Ribbon Cloud, or use plugins to connect to a wide range of
providers updated regularly.
