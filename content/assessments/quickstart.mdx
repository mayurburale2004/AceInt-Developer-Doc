# Quickstart: Create and Deploy Your First Assessment

This guide walks you through creating and publishing your first AceInt assessment—from creating the assessment to reviewing candidate results.

A basic assessment can typically be created and shared in under **10 minutes**.

Before you begin, make sure you have either:

- An existing hiring role in AceInt, or
- A list of candidate email addresses ready for invitation.

You can also create the assessment first and invite candidates later.

---

## Step 1: Open Assessments

1. Log in to AceInt.
2. Select **Assessments** from the left navigation.
3. Click **New Assessment**.

The Assessments page lists every assessment in your organization along with its status:

- Draft
- Active
- Closed

If this is your first assessment, the page will be empty.

---

## Step 2: Name Your Assessment

Give your assessment a descriptive internal name.

Example:

> Senior Backend Engineer – Python Round 1

Candidates only see this name if you also configure it as the public title.

Next, choose an assessment type.

### Coding Only

One or more AI-graded coding challenges.

### MCQ Only

Timed multiple-choice questions.

### Mixed

A combination of coding challenges and MCQs.

Click **Continue** to open the question builder.

> **Tip**
>
> Include the role, seniority level, and interview round in the assessment name.
>
> Example:
>
> `Frontend Engineer - React - Round 2`

---

## Step 3: Add Questions

Click **Add Question**.

Choose one of the supported question types.

### Coding Challenge

Configure:

- Problem statement
- Constraints
- Visible test cases
- Hidden test cases
- Starter code
- Difficulty level

### Multiple Choice Question

Configure:

- Question text
- 2–6 answer options
- Correct answer(s)
- Optional explanation

Repeat until all questions have been added.

Questions can be reordered by dragging them within the editor.

> **Note**
>
> Assessments can be saved as drafts at any time.
>
> Nothing is locked until the assessment is published.

---

## Step 4: Configure Time Limits

Open:

**Assessment Settings → Time Limits**

You can configure:

### Per-Question Time Limit

Assign a time limit to each question individually.

### Overall Assessment Time Limit

Set the maximum time allowed for the entire assessment.

Also choose a difficulty level for every coding challenge:

- Easy
- Medium
- Hard

Difficulty influences how the AI evaluates algorithmic efficiency.

---

## Step 5: Enable Anti-Cheat

Open:

**Assessment Settings → Anti-Cheat**

Available features include:

| Feature | Description |
|---------|-------------|
| Tab Switch Detection | Records whenever candidates leave the assessment tab. |
| Copy-Paste Monitoring | Logs paste events inside editors and answer fields. |
| Randomized Question Order | Delivers questions in a different order for every candidate. |
| Unique Test Case Variants | Generates different hidden coding test cases for each candidate. |

> **Warning**
>
> Anti-cheat settings cannot be modified after the first candidate begins the assessment.

---

## Step 6: Invite Candidates

You can either assign the assessment to an existing hiring role or invite candidates directly.

### Assign to a Role

Navigate to:

**Assessment Settings → Assignment**

Choose an existing role.

Candidates entering the configured hiring stage automatically receive assessment invitations.

### Invite Candidates

1. Click **Invite Candidates**.
2. Paste one or more email addresses.
3. Customize the invitation email (optional).
4. Click **Send Invitations**.

Each candidate receives a unique assessment link.

---

## Step 7: Review Results

After candidates begin submitting assessments:

1. Open the assessment.
2. Navigate to **Results**.

You'll find:

- Live leaderboard
- Candidate rankings
- Submission timestamps
- Anti-cheat indicators

Selecting a candidate opens the detailed report.

Each report includes:

- Overall score
- Question-by-question breakdown
- AI grading dimensions
- AI feedback
- Anti-cheat activity

Results can also be:

- Exported as CSV
- Shared through a read-only leaderboard link
