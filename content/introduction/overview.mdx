## Overview

Ribbon gives you everything you need to build realtime voice and video experiences: an
agents framework, frontend SDKs for every major platform, telephony connectors, and a
managed cloud to deploy it all.

## Get started

Start building with Ribbon.

- Follow the **Voice AI quickstart** to build your first agent in minutes.
- Browse **Frontends** for SDKs across web, mobile, and native platforms.
- Check **API Reference** for the CLI and SDK surface.

## Key concepts

Ribbon is organized around a few core ideas: agents that run your logic, frontends that
connect users to those agents over WebRTC, and telephony connectors that bridge phone
networks into the same realtime session.

## Getting started

```bash
npm install
npm run dev
```

Then open the dev server and explore the sidebar — every section mirrors this same layout.
