AceInt is built to work alongside the tools your team already uses. Whether you need to sync candidates from your applicant tracking system, react to real-time hiring events, or build a fully custom integration, AceInt provides three distinct integration surfaces that can be used independently or together.

Before connecting any integration, make sure you have generated an API key from **Settings → API Keys**. Most integration surfaces authenticate with that key.

## Choosing the right surface

Use **ATS Connectors** when you want a managed, no-code sync between your ATS and AceInt. Connectors handle candidate creation, stage mapping, and result delivery without writing any code.

Use **Webhooks** when your system needs to react immediately after an event occurs — for example, to trigger a downstream email, update a database record, or post a Slack notification the moment an interview is completed.

Use the **REST API** when you need fine-grained control, want to build a custom integration, or your ATS is not one of the supported connectors.

<Callout title="Tip">
Many teams combine all three surfaces: an ATS Connector to import candidates, webhooks to trigger real-time workflows, and the REST API to fetch detailed results for custom reporting.
</Callout>
